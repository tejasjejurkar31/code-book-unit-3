# List of Programs and Brief Description

| **Program** | **Brief Description** |
|-------------|-----------------------|
| **Function Overloading** | Illustrates how one function name can perform different tasks by accepting different arguments. |
| **Area Calculator** | Calculates the area of multiple shapes using separate overloaded functions. |
| **Unary Minus Operator** | Shows how the unary minus operator can be customized for a class object. |
| **Prefix & Postfix Increment** | Explains the implementation of both forms of the increment operator for objects. |
| **Complex Number Addition** | Performs addition of two complex numbers by overloading the `+` operator. |
| **Distance Comparison** | Compares two distance objects using an overloaded comparison operator. |
| **Friend Operator Overloading** | Uses a friend function to allow operations between an integer and a class object. |
| **Base Pointer Without Virtual Function** | Demonstrates compile-time binding when a base pointer accesses a derived object. |
| **Base Pointer With Virtual Function** | Shows dynamic dispatch where the correct derived function is executed through a base pointer. |
| **Base Reference With Virtual Function** | Uses a base-class reference to invoke the appropriate overridden function at runtime. |
| **Abstract Class & Pure Virtual Function** | Demonstrates creating an abstract class and implementing its pure virtual function in a child class. |
| **Collection of Shape Pointers** | Manages different shape objects through a single interface using smart pointers. |
| **Virtual Destructor** | Highlights the importance of virtual destructors for proper cleanup of derived objects. |
| **Object Slicing** | Explains how passing objects by value removes derived-class information, while references avoid this issue. |
| **Payment Processing System** | Models different payment methods using inheritance and runtime polymorphism. |
| **Employee Payroll Mini-Project** | Calculates employee salaries using abstract classes and derived employee types. |
